Phil's fantastic Snake als App (PWA)

1. Neues GitHub-Repository anlegen (z. B. "snake", public) und alle Dateien aus diesem
   Ordner hochladen (nicht den Ordner selbst). index.html muss ganz oben im Repository liegen.
2. Settings > Pages > Deploy from a branch > main / (root) > Save.
3. Nach ein bis zwei Minuten die Adresse DEIN-NAME.github.io/snake/ in Chrome auf dem
   Handy öffnen und im Menü "App installieren" wählen.

Nach Änderungen an index.html in sw.js die Zahl bei CACHE ('snake-v1') erhöhen,
damit Handys die neue Version laden.
